# glob
Найти файлы по маске в коде проекта в Buff. Вызывай, когда ищешь файл вне своего рабочего каталога.

Свой рабочий каталог ищи своим glob: этот видит только проект в Buff, пути — от его корня, модули —
в sources/<модуль>. Примеры маски: **/*.ts, sources/**/config*.

## pattern
маска файлов

## path
каталог поиска от корня проекта; пустая строка — весь проект

## hidden
true — со скрытыми файлами и каталогами

## limit
сколько файлов вернуть; 0 — 100

## branch
ветка проекта; пустая строка — основная

## cursor
0 — с начала; иначе число из прошлого ответа, где сказано продолжить

# grep
Найти строки по регулярному выражению в коде проекта в Buff. Вызывай до того, как гадать о соседнем коде.

Свой рабочий каталог ищи своим grep: этот видит только проект в Buff, пути — от его корня. Ищет и в
тексте документов Word, Excel, PowerPoint и PDF. Ответ — файлы с номерами строк.

## pattern
регулярное выражение или точный текст (см. literal)

## path
файл или каталог от корня проекта; пустая строка — весь проект

## include
маска файлов, например *.ts или *.{ts,tsx}; пустая строка — все

## literal
true — pattern как точный текст, не регулярное выражение

## caseSensitive
true — с учётом регистра (обычно)

## limit
сколько строк-совпадений вернуть; 0 — 100

## branch
ветка проекта; пустая строка — основная

## cursor
0 — с начала; иначе число из прошлого ответа, где сказано продолжить

# read
Прочитать файл или каталог из кода проекта в Buff. Вызывай, когда нашёл место через glob или grep.

Свои файлы читай своим read: этот видит только проект в Buff, путь — от его корня. Строки
пронумерованы; документы Word, Excel, PowerPoint и PDF читаются текстом. Большой файл читай частями
через offset и limit.

## path
путь от корня проекта

## offset
с какой строки (с 1); 0 — с начала

## limit
сколько строк; 0 — 2000

## branch
ветка проекта; пустая строка — основная

## cursor
0 — с начала; иначе число из прошлого ответа, где сказано продолжить
