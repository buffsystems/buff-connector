# list_entries
Список записей базы знаний этого контекста, без тел. Вызывай перед write_entry, чтобы не завести дубль.

Каждая запись: имя, заголовок, описание одной строкой, тип, область и автор. Запись с
always_in_prompt уже приведена целиком в твоём промпте.

# read_entry
Прочитать запись базы знаний по имени из индекса. Вызывай, как только строка индекса отвечает на вопрос.

Делай это до того, как придумывать ответ или лезть в код. Возвращает {found, body, scope, author};
для записи, которая уже приведена в промпте целиком, тело не повторяется (inlined: true).

## name
имя записи (латиницей, из индекса знаний)

# write_entry
Добавить запись в базу знаний: вызов сам спрашивает пользователя формой. Не пиши «добавляю» — вызывай.

Вызывай В МОМЕНТ, когда пользователь просит что-то запомнить или формулирует правило, когда
выяснил устойчивый факт об окружении или проекте, или наткнулся на воспроизводимое препятствие и
нашёл обход. Без «да» пользователя ничего не записывается; written: false — он отказался, не
предлагай эту запись снова. scope: org (вся организация) или имя проекта либо пространства из
рабочего контекста.

## name
имя-адрес записи латиницей через дефис

## title
заголовок для человека

## description
одна строка: о чём запись — по ней модель решает, читать ли тело

## type
rule — правило работы; fact — как здесь устроено; pitfall — препятствие и обход

## scope
org или имя проекта/пространства из рабочего контекста

## body
тело в markdown: что именно нужно знать
