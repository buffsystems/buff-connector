# search_pages
Найти страницы и базы данных Notion по словам — в заголовках И в тексте страниц области (сам Notion
ищет только по заголовкам; текст интеграция читает и ищет сама, слова сравниваются по основе, так
что падежи не мешают). Использовать ПЕРВЫМ делом, когда вопрос касается требований, регламентов,
решений или того, «как у нас принято»; затем читать найденное get_page или query_database.

# get_page
Прочитать страницу Notion целиком — текст с заголовками, списками, таблицами и кодом — вместе с
обсуждением. Использовать, когда поиск нашёл подходящую страницу или когда в вопросе назвали её
адрес.

# get_page_children
Перечислить вложенные страницы и базы данных раздела. Использовать, когда ответ собирается из
нескольких страниц одного раздела.

# get_database
Устройство базы данных Notion: её источники данных и свойства с типами. Использовать перед
query_database, чтобы знать, по какому свойству фильтровать.

# query_database
Прочитать записи базы данных Notion (по ключу базы или источника данных), при желании отфильтровав
по значению одного свойства. Каждая запись — её свойства текстом.

# get_comments
Обсуждения страницы Notion: ветки комментариев, кто и когда писал. Использовать, когда важно, что
уже обсуждали по этой странице.

# add_comment
Написать комментарий на странице Notion — или ответить в ветке, если ключ вида СТРАНИЦА#обсуждение.

# create_page
Создать дочернюю страницу Notion из markdown внутри области подключения — под указанной родительской
страницей. Использовать, когда результат нужно оставить в Notion документом, а не комментарием.
