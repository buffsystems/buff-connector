# search_issues
Найти задачи и pull request в подключённых репозиториях по тексту. Использовать, когда в задаче
упомянут номер или нужен контекст из трекера клиента.

# get_issue
Прочитать задачу или pull request целиком, вместе с обсуждением. Использовать, когда нужен текст
требований, критерии приёмки или ход обсуждения.

# get_pull_diff
Прочитать изменения pull request одним diff. Использовать, когда вопрос касается того, что именно
меняет этот pull request.

# add_comment
Написать комментарий в задачу или pull request.
