# list_files
Перечислить макеты (файлы Figma), к которым подключён бот: ключ, название, проект. Использовать
ПЕРВЫМ делом, когда вопрос про дизайн, экран, макет или токены, а ключ файла в вопросе не назван.
Поле area говорит, какова область: если это все файлы учётной записи, в списке только те, где бота
упоминали, а любой другой файл открывается по ключу из ссылки figma.com/design/КЛЮЧ/….

# get_file
Структура макета: страницы, фреймы и их размеры, вложенность до заданной глубины, список стилей и
компонентов файла. Использовать, чтобы понять, из чего состоит файл, и выбрать узел (id вида 1:23)
для get_node. depth=1 — только страницы, 2 — страницы и фреймы верхнего уровня (по умолчанию),
больше — глубже.

# get_node
Узел макета с поддеревом и всеми параметрами: положение и размер, автолейаут (направление, отступы,
интервалы, выравнивание), заливки и обводки в hex, скругления, эффекты, типографика и тексты,
привязанные стили и переменные по именам, компонент экземпляра и его свойства. Использовать, когда
нужны точные значения экрана, блока или элемента (id вида 1:23 — из get_file или search_nodes).

# get_styles
Дизайн-токены файла: опубликованные стили со значениями (цвета в hex, типографика, эффекты, сетки),
стили, использованные в файле, и переменные с значениями по режимам (тема, размер) — там, где план
Figma даёт их читать. Использовать, когда вопрос про палитру, шрифты, токены или дизайн-систему.

# search_nodes
Найти узлы макета по словам в имени слоя или в тексте: возвращает id, тип, страницу и путь.
Использовать, когда в вопросе назван экран, кнопка, поле или текст, а его id неизвестен; дальше —
get_node. types — необязательный список типов (frame, text, instance, component).

# get_comments
Обсуждения макета: ветки комментариев с ответами, к какому узлу приколоты, кто и когда писал, решено
ли. Использовать, когда вопрос про замечания, договорённости или историю обсуждения экрана.

# render_node
Отрисовать узел макета в PNG и показать картинку. ТОЛЬКО для модели, которая читает изображения;
параметры узла всегда доступны через get_node без картинки. Использовать, когда важно увидеть
композицию целиком, а не значения. scale — масштаб 0.5–4.

# add_comment
Написать комментарий в обсуждение макета.
