# glob
Найти файлы по имени — шаблон вида "*.docx", "**/*.xlsx", "договор*" (регистр не важен). Без path
ищет по всей области, с path — в этой папке и вложенных. Возвращает пути, новые сначала.
Использовать, когда нужен файл по имени или расширению; содержимое ищет grep. Это папки КОМПАНИИ на
диске и сетевых папках клиента — не репозиторий проекта. Область подключения: {{area}}.

## pattern
Шаблон имени: * ? и ** для вложенных папок

## path
Папка, в которой искать; пусто — вся область

# grep
Найти по содержимому — регулярное выражение по тексту файлов области (регистр не важен): документы
Word, таблицы Excel, презентации PowerPoint (и старые .doc/.xls/.ppt), PDF и текстовые файлы
читаются как текст. Возвращает файл, номер строки и строку; номер строки тот же, что покажет read.
path сужает до папки, include — до имён ("*.pdf", "*.{doc,docx}"). Использовать ПЕРВЫМ делом, когда
вопрос касается регламентов, договоров, планов, цифр — того, что записано в файлах. Это папки
КОМПАНИИ на диске и сетевых папках клиента — не репозиторий проекта. Область подключения: {{area}}.

## pattern
Регулярное выражение (Python), регистр не важен

## path
Папка или файл; пусто — вся область

## include
Шаблон имён файлов, например *.docx или *.{xls,xlsx}

# read
Прочитать файл или папку по абсолютному пути (локальному /srv/… или сетевому \\сервер\папка\…,
smb://сервер/папка/…). Документ Word приходит как markdown, таблица — листами-таблицами, презентация
— слайдами с заметками, PDF — постранично, текстовый файл — как есть; строки пронумерованы «N:
текст». Папка — списком записей, папки со слэшем на конце. По умолчанию файл читается ЦЕЛИКОМ;
offset (с какой строки, от 1) и limit (сколько строк) — если нужна часть. Использовать, когда путь
известен или найден через glob/grep. Это папки КОМПАНИИ на диске и сетевых папках клиента — не
репозиторий проекта. Область подключения: {{area}}.

## filePath
Абсолютный путь к файлу или папке

## offset
Первая строка (от 1); пусто — с начала

## limit
Сколько строк; пусто — до конца
