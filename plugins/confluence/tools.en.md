# search_pages
Find pages in the connected spaces by text. Use it FIRST when the question is about requirements,
regulations, architecture decisions or "how things are done here".

# get_page
Read a page in full, together with its discussion. Use it when search found a fitting page or when
the question names its address.

# get_page_children
List the child pages of a section. Use it when the answer is put together from several pages of one
section.

# add_comment
Write a comment on a page.
