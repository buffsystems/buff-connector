# search_pages
Найти страницы в подключённых пространствах по тексту. Использовать ПЕРВЫМ делом, когда вопрос
касается требований, регламентов, архитектурных решений или того, «как у нас принято».

# get_page
Прочитать страницу целиком, вместе с обсуждением. Использовать, когда поиск нашёл подходящую
страницу или когда в вопросе назвали её адрес.

# get_page_children
Перечислить дочерние страницы раздела. Использовать, когда ответ собирается из нескольких страниц
одного раздела.

# add_comment
Написать комментарий на странице.
