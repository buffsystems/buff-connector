# search_issues
Найти задачи и merge request в подключённых проектах по тексту. Использовать, когда упомянут номер
или нужен контекст из трекера клиента.

# get_issue
Прочитать задачу или merge request целиком, вместе с обсуждением. Использовать, когда нужен текст
требований, критерии приёмки или ход обсуждения.

# get_merge_diff
Прочитать изменения merge request одним списком diff. Использовать, когда вопрос касается того, что
именно меняет этот merge request.

# add_comment
Написать комментарий в задачу или merge request.
