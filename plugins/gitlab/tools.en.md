# search_issues
Find issues and merge requests in the connected projects by text. Use it when a number is mentioned
or context from the client's tracker is needed.

# get_issue
Read an issue or a merge request in full, together with its discussion. Use it when the text of the
requirements, the acceptance criteria or the course of the discussion is needed.

# get_merge_diff
Read a merge request's changes as one list of diffs. Use it when the question is about what exactly
this merge request changes.

# add_comment
Write a comment on an issue or a merge request.
