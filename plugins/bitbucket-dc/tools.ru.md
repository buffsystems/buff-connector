# search_pulls
Найти pull request в подключённых репозиториях по тексту. Использовать, когда упомянут номер или
нужен контекст из ревью клиента.

# get_pull
Прочитать pull request целиком, вместе с обсуждением. Использовать, когда нужен замысел изменения
или ход обсуждения в ревью.

# get_pull_diff
Прочитать изменения pull request одним diff. Использовать, когда вопрос касается того, что именно
меняет этот pull request.

# add_comment
Написать комментарий в pull request.
