# search_pulls
Find pull requests in the connected repositories by text. Use it when a number is mentioned or
context from the client's review is needed.

# get_pull
Read a pull request in full, together with its discussion. Use it when the intent of a change or
the course of the discussion in a review is needed.

# get_pull_diff
Read a pull request's changes as one diff. Use it when the question is about what exactly this pull
request changes.

# add_comment
Write a comment on a pull request.
