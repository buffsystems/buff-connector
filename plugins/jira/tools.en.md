# search_issues
Find tickets by JQL. Use it when the task mentions a ticket key or context from the client's tracker
is needed.

# get_issue
Read a ticket in full, together with its comments. Use it when the text of the requirements, the
acceptance criteria or the discussion in the ticket is needed.

# add_comment
Write a comment on a ticket.
