# web_search
Искать в публичном интернете. Обращайся к нему, когда ответ зависит от сведений свежих, внешних или
отсутствующих в проекте и базе знаний: заметки к выпуску библиотеки, текст ошибки, стандарт,
документация поставщика, цена, дата. Возвращает заголовки, адреса и выдержки; многообещающий
результат прочитай через web_fetch. Результаты, которые исключают списки администратора, не
показываются.

## query
Что искать — так, как ввёл бы это в поиск

# web_fetch
Прочитать публичную веб-страницу по адресу — документацию, статью, README, ответ JSON. Используй, как
только у тебя есть адрес: из задачи, из разговора или из web_search. HTML возвращается текстом с
сохранёнными заголовками, списками, таблицами и ссылками; страница целиком, без обрезки. Адрес,
который исключают списки администратора, внутренний адрес или тип содержимого вне разрешённых
отклоняется с указанием причины.

## url
Полный адрес, с http:// или https://
