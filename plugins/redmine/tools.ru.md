# search_issues
Найти задачи в подключённых проектах по тексту. Использовать, когда упомянут номер задачи или нужен
контекст из трекера клиента.

# get_issue
Прочитать задачу целиком, вместе с обсуждением. Использовать, когда нужен текст требований, критерии
приёмки или ход обсуждения.

# add_comment
Написать комментарий в задачу.
