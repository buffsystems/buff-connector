# search_issues
Find issues in the connected projects by text. Use it when an issue number is mentioned or context
from the client's tracker is needed.

# get_issue
Read an issue in full, together with its discussion. Use it when the text of the requirements, the
acceptance criteria or the course of the discussion is needed.

# add_comment
Write a comment on an issue.
