# search_issues
Найти задачи по JQL. Использовать, когда в задаче упомянут ключ тикета или нужен контекст из трекера
клиента.

# get_issue
Прочитать тикет целиком, вместе с комментариями. Использовать, когда нужен текст требований,
критерии приёмки или обсуждение в тикете.

# add_comment
Написать комментарий в тикет.
