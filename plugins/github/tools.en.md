# search_issues
Find issues and pull requests in the connected repositories by text. Use it when a number is
mentioned or context from the client's tracker is needed.

# get_issue
Read an issue or a pull request in full, together with its discussion. Use it when the requirements,
the acceptance criteria or the course of the discussion are needed.

# get_pull_diff
Read a pull request's changes as one diff. Use it when the question is about what exactly this pull
request changes.

# add_comment
Write a comment on an issue or a pull request.
