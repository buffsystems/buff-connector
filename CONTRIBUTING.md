# Contributing

Thank you for helping with the Buff connector. Issues and pull requests are welcome.

This repository is a **snapshot**: each Buff release adds one commit with the source of that
release, and development happens in our tree. When we accept a pull request, we apply the change
there — your authorship is kept in the commit — and it appears here with the next release; we then
close the pull request with a link to it.

Please keep one focused change per pull request, run the tests (`make test`), and explain why in
the description. For a larger change, open an issue first.
